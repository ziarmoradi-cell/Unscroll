# Unscroll 1.2.1

**Das aktuelle native iPhone-Projekt liegt im Ordner [Unscroll_Xcode_V1](Unscroll_Xcode_V1).**

Das neue Update enthält Intro, neues Design, Kamera-Training mit Rekorden, Schrittbelohnungen,
Fokus mit Offline-Klängen, Nachtpause und Wecker, Detox-Programme, Tipps und Game-Center-Freunde.

1. Dieses Repository herunterladen (**Code → Download ZIP**) und entpacken.
2. `Unscroll_Xcode_V1/Unscroll.xcodeproj` in Xcode öffnen.
3. Der [kurzen Installationsanleitung](Unscroll_Xcode_V1/START-HIER.md) folgen.

Die alte Datei `Unscroll_Xcode_V1(1).zip` ist ein historischer Stand und enthält dieses Update **nicht**.
GitHub aktualisiert eine bereits auf dem iPhone installierte App nicht automatisch.

Version 1.2.1 / Build 4 · iOS 17.4+ · Systemwecker ab iOS 26 mit Xcode 26+.
